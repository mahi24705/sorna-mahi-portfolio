## 🚀 Quick Start (Run Locally)

### Prerequisites
- Node.js (v18.0 or higher)
- npm (v9.0 or higher)

### 1. Clone or Open the Repository
```bash
git clone https://github.com/mahi24705/sorna-mahi-portfolio.git
cd sorna-mahi-portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000` (or the port shown in terminal).

### 4. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.

## ☁️ Free Deployment to Vercel

### Method A: Deploy via Vercel Web Dashboard (Easiest)
1. Go to [vercel.com](https://vercel.com/) and sign in with your GitHub account (`mahi24705`).
2. Click **"Add New..."** &rarr; **"Project"**.
3. Import your `sorna-mahi-portfolio` repository.
4. Leave settings as default (Framework Preset: **Vite**, Build Command: `npm run build`, Output Directory: `dist`).
5. Click **"Deploy"**. Your website will be live worldwide with free SSL in less than 60 seconds!

### Method B: Deploy via Vercel CLI
```bash
npm install -g vercel
vercel
```
